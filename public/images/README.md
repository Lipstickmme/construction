# Image drop folder

Slots are declared in `src/data/images.ts`. Any slot without a file renders a
labelled placeholder naming the file it wants — drop a matching file in and it
appears on reload, no code change.

## Logos

Both arrived as solid 1024² squares, which read as a filled box over
photography. Re-cut to transparent PNGs trimmed to the wordmark, alpha taken
from luminance so the antialiased edges survive.

| File | Lettering | Use on |
| --- | --- | --- |
| `axis-logo-light.png` | Light | Dark backgrounds — hero, drawer, footer |
| `axis-logo-dark.png` | Dark | Light backgrounds — scrolled header |
